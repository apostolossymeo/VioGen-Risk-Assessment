## Engine API

- `DocumentaryScenario` → `Scenario`. The old name remains as an alias.
- New fields:
  - `case_status`, `first_vper_done`, `known_new_incident`;
  - `special_relevance`, `minors_in_care`;
  - the inactivation premises: `victim_contacted`, `reassessed_after_first_judicial_action`, `reassessment_raised_level`, `evaluator_judgement_supports_inactivation`;
  - the supervision criteria;
  - `months_since_last_assessment`.
- Unknown premises are `None` and give `cannot_determine`. In v1, `None` was treated as unmet.
- New functions:
  - `assessment_instrument`, `vper_court_notification`, `case_status_rule`;
  - `supervision`, `exceptional_inactivation`, `reactivation`;
  - `protection_floor` (from the full annexes), `trace`.
- `later_vper` returns value, unit and bound (`strictly_before`). Extremo is expressed in hours (72).
- `ordinary_inactivation` returns:
  - `not_eligible` when judicial measures are in force;
  - `routes_to_supervision` in 2025 when a supervision criterion is met.
